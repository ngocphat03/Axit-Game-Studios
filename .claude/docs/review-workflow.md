# Quy trình đánh giá (Review Workflow)

1. Thay đổi code yêu cầu sự đánh giá từ agent trưởng bộ phận tương ứng
2. Thay đổi thiết kế yêu cầu ký duyệt từ `game-designer` và `creative-director`
3. Thay đổi kiến trúc yêu cầu ký duyệt từ `technical-director`
4. Thay đổi liên lĩnh vực yêu cầu ký duyệt từ `producer`
