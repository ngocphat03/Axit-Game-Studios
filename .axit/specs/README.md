# Axit Specs

This directory will contain compact format contracts for Axit-owned artifacts such as Profiles, Skills, Workflows, project manifests, and registries.

The specifications are intentionally not populated yet. We will define or move each contract only when the first accepted Core artifacts need it.

Rules:

- Codex compatibility must not dictate the whole Axit architecture.
- A Core Skill must still be expressible as a valid Codex `SKILL.md`.
- Avoid speculative schema fields that have not been exercised by a real Core artifact.
