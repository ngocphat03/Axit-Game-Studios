# Core Profiles

Reviewed Axit Core Profiles live here.

Current active Core Profiles:

- [`technical-architect`](technical-architect/PROFILE.md) — owns technical structure, system boundaries, shared-state ownership, and cross-system contracts.
- [`game-designer`](game-designer/PROFILE.md) — owns game intent, player-facing rules, core loops, and design acceptance criteria.
- [`implementation-engineer`](implementation-engineer/PROFILE.md) — translates accepted design and architecture into bounded, maintainable, and testable project changes.
- [`quality-verifier`](quality-verifier/PROFILE.md) — independently evaluates whether project changes satisfy accepted requirements with sufficient evidence.

Together these form the default Core responsibility loop:

```text
Game Designer -> Technical Architect -> Implementation Engineer -> Quality Verifier
```

Not every task needs all four Profiles. Load only the responsibility lenses relevant to the current work.

Treat this four-Profile set as complete for Core v1 unless a real project demonstrates a responsibility gap that cannot be handled through a Skill, Knowledge artifact, project rule, or project-specific Profile.

Legacy Game Studios agents are reference material only. They are not migrated by default.
