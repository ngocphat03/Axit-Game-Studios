# Core Profiles

Reviewed Axit Core Profiles live here.

Current active Core Profiles:

- [`technical-architect`](technical-architect/PROFILE.md) — owns technical structure, system boundaries, shared-state ownership, and cross-system contracts.
- [`game-designer`](game-designer/PROFILE.md) — owns game intent, player-facing rules, core loops, and design acceptance criteria.

A Profile may enter Core only after we confirm that its responsibility is reusable across materially different game projects and is not better represented as a Skill, Knowledge artifact, or project-specific specialization.

Legacy Game Studios agents are reference material only. They are not migrated by default.
